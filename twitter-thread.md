# pplx-zero Twitter Thread

## 1 - Hook

Your AI agents need real-time web search. Not stale training data.

Built a CLI that pipes Perplexity directly into your workflows.

900 lines. 1 dep. Perfect for agent toolchains.

---

## 2 - Demo

```
pplx "what is bun"
```

Streams answers. Renders markdown. Done.

---

## 3 - Local RAG

Index your notes:

```
pplx --ingest ./docs/
```

Query with your knowledge:

```
pplx -l "my rust notes"
```

Your docs become context. Perplexity answers with YOUR data.

---

## 4 - Files

```
pplx -f paper.pdf "summarize"
pplx -i screenshot.png "explain"
pplx -c "tell me more"
```

PDFs. Images. Conversations. All from terminal.

---

## 5 - Stack

- 1 dependency (zod)
- ~900 lines TypeScript
- Bun runtime
- SQLite FTS5
- No frameworks

If it doesn't need to exist, it doesn't.
